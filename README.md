# 🔐 Login Form

A simple and clean Login Form website built using HTML and CSS. The project focuses on creating a modern and user-friendly login interface with a simple and attractive design.

## ✨ Features

🔐 User login form  
📧 Email/username input field  
🔑 Password input field  
☑️ Remember me option  
🚀 Login button  
🎨 Clean and simple UI  
📱 User-friendly layout  

## 🛠️ Technologies

HTML5  
CSS3

## 📌 Project Goal

The main goal of this project was to practice creating a clean and structured login form using HTML and CSS.
